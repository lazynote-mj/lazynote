# Lazynote Korean Editing

한국어로 정확하고 자연스럽게 읽히도록 고친다. 규범상 오류, 이해를 방해하는 표현, 필자의 문체 선택을 구분한다. 표현 하나만으로 AI 작성 여부를 판정하지 않는다.

## 요청 범위와 문체

최신 원문과 요청을 먼저 읽는다. 원고가 있으면 책·연재 기획 인터뷰 없이 편집을 시작한다. 용도와 독자, 종결어미, 필자의 목소리는 원문과 프로젝트 자료에서 파악하고, 결과를 크게 바꾸는 정보가 없을 때만 묻는다.

| 요청 | 기본 범위 |
| --- | --- |
| 맞춤법·띄어쓰기만 | 명확한 표기 오류만 수정. 어휘·문장 순서·말투는 유지 |
| 교정·교열 | 표기, 조사·어미, 문장 호응, 지시 대상, 표현·표기 일관성 점검 |
| 윤문·자연스럽게 | 교정·교열에 더해 번역투, 중복, 수식 범위, 문장 연결과 리듬을 필요한 만큼 수정 |
| 진단만 | 원문을 바꾸지 않고 문제와 수정안을 제시 |

별도 강도 지정 없이 ‘다듬어줘’라고 하면 의미·문체를 유지하는 윤문을 한다. 글 전체를 다른 필자의 글로 다시 쓰지 않는다. ‘맞춤법만’ 요청에서 발견한 내용상의 모호함은 고치지 않고 별도로 짚는다.

프로젝트 지침과 필자 고유의 문체가 일반적인 스타일 선호보다 우선한다. 규범상 오류는 바로잡되 의도적인 방언·대화체·인용·상표 표기는 문맥에 따라 유지한다. 에세이에 분석 아티클의 `~다`체, 질문형 제목, 구어체 금지를 가져오지 않는다.

## 교정과 윤문

실제 작업 전에 [references/korean-editing-guide.md](references/korean-editing-guide.md)를 읽고 요청 범위에 해당하는 항목만 적용한다. 긴 원고는 문단·절의 경계를 유지하며 나누어 살피고, 마지막에는 전체 연결과 용어·말투의 일관성을 본다.

1. **보존할 내용을 파악한다.** 고유명사, 수치·단위·날짜, 직접 인용, 전문용어, 사실·의견의 구분, 부정·조건·확률·의무의 강도를 확인한다.
2. **문제의 성격을 진단한다.** 표기 오류인지, 호응이나 수식 문제인지, 문맥 또는 문체 선택인지 구분한다. 짧은 문장에는 과도한 진단 보고서를 붙이지 않는다.
3. **필요한 부분만 고친다.** 단어를 일괄 치환하지 않는다. 같은 표현도 문법적 역할과 문맥에 따라 판단한다. 맞는 문장은 그대로 둔다.
4. **원문과 대조한다.** 누가 무엇을 했는지, 부정·조건·범위·시점이 같은지 확인한다. 문장을 자연스럽게 만들다가 원문에 없는 사실이나 인과를 넣지 않았는지 본다.
5. **이어 읽는다.** 앞뒤 문장과 문단 사이에서 지시 대상과 논리 관계를 확인한다. 문장만 좋아지고 절의 의미가 달라지면 수정한다.

문장 분리·병합은 논리 관계가 더 분명해질 때 한다. 문단 경계는 기본적으로 유지하되 문단 편집까지 요청받았거나 문단을 나누는 것이 이해에 필요한 경우에만 논증 단위를 보존하며 조정한다. 구조 재편이나 주장 삭제가 필요한 문제는 문장 윤문으로 해결한 척하지 말고 별도 제안으로 구분한다.

## 의미와 사실을 보존하는 경계

- `일부`를 `모두`로, `관련이 있다`를 `원인이다`로, `가능하다`를 `일어날 것이다`로 바꾸지 않는다. 이중 부정을 풀 때도 강도를 유지한다.
- `~것으로 보인다`, `~할 수 있다`가 근거의 한계나 가능성을 나타내면 남긴다. 어미를 다양하게 만들기 위해 확률을 바꾸지 않는다.
- 수치·날짜·단위·고유명사의 값은 바꾸지 않는다. 숫자와 단위의 띄어쓰기처럼 표기만 손볼 수 있지만, 직접 인용·공식 명칭은 임의로 정정하지 않는다.
- 원문의 생략된 주체나 대상을 문맥에서 하나로 확정할 수 있을 때만 보충한다. 해석이 갈리면 추측해서 채우지 말고 해당 부분을 표시한다. 나머지 확실한 교정은 계속한다.
- 직접 인용, 링크 주소, 각주 식별자, 코드와 수식은 보존한다. 인용 안의 오타가 의심되면 원문 확인이 필요하다고 별도 기록한다.
- 원고에 사실 오류가 의심되면 윤문 변경과 분리한다. 문체 교정을 마쳤다는 이유로 사실 검증도 완료했다고 말하지 않는다.

## 규범 확인과 도구

확신할 수 있는 교정은 직접 수행한다. 표준 표기나 허용되는 복수 표기가 불확실하면 국립국어원 어문 규범·표준국어대사전·우리말샘 등 적절한 공식 자료에서 해당 표현을 확인한다. 사전 등재 여부와 문맥에 맞는 뜻을 구분하고, 확인하지 못한 표현을 규범상 오류로 단정하지 않는다.

외부 검사기는 필수가 아니다. 사용할 때는 실제 이용 조건과 전송할 원문의 성격을 확인하며, 검사 결과를 문맥 판단 없이 일괄 수용하지 않는다. 외부 검사기를 쓰지 않았으면 검사기를 통과했다고 쓰지 않는다.

정확한 글자수 요청이 있을 때만 공백 포함 여부 등 계수 기준을 정해 실제로 센다. ‘정확히 N자’에 임의의 허용 오차를 적용하지 않는다. 분량을 늘리기 위해 없던 경험·주장을 추가하지 않는다.

## 결과 전달

기본은 바로 사용할 수 있는 교정·윤문본과 필요한 경우 주요 변경 이유를 짧게 전달하는 것이다. ‘결과만’이면 결과만 낸다. 비교 요청에는 `원문 / 수정안 / 이유`로 보여준다. 규범상 교정과 선택 가능한 스타일 제안은 구분한다.

파일 편집 요청에서는 지정된 파일과 범위에 반영하고 프로젝트의 원고 동기화 규칙을 따른다. 제목 교정만으로 폴더 이름이나 발행 메타데이터를 바꾸지 않는다.
