# Lazynote Title and Outline

제목과 목차를 내용의 포장이나 분류표가 아니라 **글의 약속과 사고의 경로**로 설계한다.

## 필요한 재료 파악

필자가 실제로 말하려는 중심 문장, 독자의 이해가 어떻게 달라져야 하는지, 이 글만이 제공하는 경험·관점·판단 기준, 필자의 목소리와 피해야 할 과장, 단일 아티클인지 시리즈·책인지를 먼저 찾는다.

프로젝트 자체가 처음이라 목적·독자·전체 목차가 아직 없으면 `../../shared/intake.md`의 기획 인터뷰부터 한다.

재료가 부족하면 제목을 확정하는 척하지 말고, 현재 가능한 가제와 확인해야 할 질문을 구분한다.

## 제목 설계

좋은 제목은 소재만 가리키지 않고 다음 중 적어도 하나를 담는다.

- 통념과 실제 경험 사이의 긴장
- 두 개념의 중요한 구분
- 생각이 바뀌는 전환
- 독자가 자기 문제로 가져갈 질문
- 글 전체를 지탱하는 정확한 문장

후보를 무작정 많이 만들지 않는다. 기본값은 `가장 정확한 안`, `가장 읽고 싶게 만드는 안`, `필자의 개성이 가장 강한 안`의 세 가지다. 각 후보가 무엇을 약속하며 어떤 위험이 있는지 한 줄로 설명하고 최종 추천 하나를 고른다. 본문보다 더 큰 약속을 하는 제목은 제외한다.

영어 제목은 뜻뿐 아니라 관사, 단수·복수, 원어민에게 들리는 어감과 브랜드로서의 의도적 생략을 구분해 설명한다.

## 단일 아티클의 구성

목차나 소제목은 독자의 이해가 변하는 순서로 배치한다.

1. 독자는 어떤 장면 또는 문제 앞에 서는가?
2. 기존 설명은 어디에서 충분하지 않은가?
3. 무엇을 구분하거나 다시 정의해야 하는가?
4. 어떤 경험·근거·반례가 새 관점을 지지하는가?
5. 독자는 어떤 기준이나 질문을 가지고 나가는가?

이 질문을 그대로 소제목으로 복사하지 않는다. 글의 성격에 맞춰 필요한 단계만 쓰며, 각 소제목은 바로 뒤 내용의 요약보다 앞뒤 생각을 잇는 역할을 하게 한다.

## 시리즈·책의 목차

먼저 책 전체를 한 문장으로 정의한 뒤 부와 장을 설계한다.

- 부는 소재의 분류가 아니라 독자의 큰 인식 변화를 맡는다.
- 각 장은 하나의 독립된 질문 또는 판단 기준을 맡는다.
- 인접한 장이 사실상 같은 말을 하는지 확인한다.
- 개인에서 관계와 구조, 쉬운 문제에서 어려운 문제 등 책에 맞는 진행 원리를 하나 선택한다.
- 프롤로그는 책을 쓰게 된 이유와 독자와의 관계를 세운다.
- 에필로그는 본문을 요약하기보다 책의 태도를 남긴다.
- 필자의 실제 경험 범위를 넘어가는 장은 가제 또는 탐색 항목으로 표시한다.

상세 기준은 [references/review-checklist.md](references/review-checklist.md)를 사용한다.

## 진단과 수정

기존 제목·목차를 검토할 때는 전면 대체부터 하지 않는다. 현재 안이 약속하는 내용, 실제 원고와 맞는 부분, 겹침·공백·순서 문제·과장된 약속, 유지할 표현을 짚고 최소 수정안을 먼저 낸다. 필요할 때만 재구성안을 추가한다.

## 기본 산출 형식

- 중심 문장
- 추천 제목과 부제
- 방향이 다른 대안 2개
- 목차와 각 항목의 역할 한 줄
- 구성 원리
- 아직 실제 경험이나 근거가 필요한 항목

사용자가 제목만 요청했다면 불필요한 전체 목차를 덧붙이지 않는다.
