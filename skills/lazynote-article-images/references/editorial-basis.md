# 기준의 근거와 적용 범위

이 문서는 이전에 작업한 한 연재의 시각 편집 지침 문서, 이미 발행된 여러 편의 SVG 도표, Lazynote의 `lazynote-case-writing/references/format.md`를 2026-09-07에 확인해 정리했다. 이식 가능한 요약이며 원래 저장소의 절대 경로나 별도 도구에 의존하지 않는다. 작업 프로젝트에 최신 지침이 있으면 그것을 따른다.

## 문서에서 확인한 판단

- 본문 시각자료의 기본은 논증 압축과 비교를 위한 직접 제작 도표다.
- 사실·논리 검증 후 제작하고, SVG와 업로드용 PNG를 함께 관리한다.
- 출처 표기는 외부 이미지의 이용허락을 대신하지 않는다. 기존 연재는 캐릭터·스틸·서비스 화면 복제보다 공식 원문 링크를 택했다.
- 모든 글에 억지로 이미지를 넣지 않았다. 당시 계획은 단계와 갈래가 핵심인 09·10번을 우선하고, 그림 없이도 논지가 서는 07·08번은 뒤로 미뤘다. 이는 당시 판정이며 현재 제작 상태를 뜻하지 않는다.
- 표지 계획은 장식을 많이 넣기보다 관심이 관계와 기록을 거쳐 자산으로 남는 흐름을 선이나 원형 구조로 표현하는 방향이었다. 확정된 AI 일러스트 화풍이나 생성 프롬프트는 확인되지 않았다.

## 아티클별 선택을 일반화하면

| 확인한 사례 | 이미지가 맡은 역할 | 다른 글에 적용할 판단 |
| --- | --- | --- |
| 01 좋아함·관계·반복 행동·자산의 구조 | 추상 개념을 독자가 따라갈 순서로 보여줌 | 중간 조건을 생략한 자동 성장의 화살표로 만들지 않음 |
| 02 문화마케팅 성과의 4단계 | 노출·경험, 브랜드 자산, 관계자산, 재무 효과를 구분 | 단계마다 확인 가능한 성과가 다름을 보존 |
| 03 라이선스 매출과 매출총이익률 | 수익 지표를 보여주되 자산 축적과 혼동하지 않음 | 매출·이익·자산을 같은 척도로 그리지 않음 |
| 04 같은 거래, 다른 기록 경로 | 채널을 빌린 기업과 플랫폼 운영 기업에 남는 기록 비교 | 고객 소유가 아니라 동의받은 관계를 다시 이어갈 경로를 표현 |
| 05 IP 밸류체인의 서로 다른 출발점 | 기업별 출발점과 경로 차이를 비교 | 회사 로고 나열 대신 논증에 필요한 차이를 시각화 |
| 06 접점 확대가 자산으로 남는 조건 | 접점 수와 관계 회수 조건을 구분 | 접점이 늘면 자동으로 자산이 된다는 오해를 막음 |

## 기존 도표에서 관찰한 스타일

04번 SVG는 1200×675, 따뜻한 아이보리 배경(`#F7F4EE`), 짙은 본문(`#202020`), 옅은 녹색 패널과 녹색 경로, 보조 갈색, 둥근 사각형, 한국어 산세리프를 사용한다. 상단에는 제목과 짧은 설명, 가운데에는 비교 구조, 하단에는 해석 문구와 제작 명의를 놓았다.

이것은 기존 결과물에서 관찰한 출발점이지 모든 프로젝트의 의무 규격이 아니다. 같은 연재에서는 기존 파일을 보고 색과 밀도를 맞추되, 원고에 더 잘 맞으면 세로 배치나 분할을 선택한다. 과거 파일을 그대로 복제하지 말고 작은 화면의 글자 크기, 화살표 끝, 하단 문구 간격까지 다시 확인한다. 폰트가 없는 환경에서는 사용 가능한 한글 폰트를 확인한다.

## 새로 제안한 AI 생성 기본값

다음은 과거 승인 이력으로 주장하지 않는 확장안이다.

- 한 이미지에는 중심 장면이나 시각적 비유 하나를 우선한다.
- 기존 연재와 함께 쓴다면 절제된 색과 여백을 출발점으로 삼는다. 사진풍·수채화·3D 등 특정 화풍을 고정하지 않는다.
- 요청이 없으면 이미지 속 문자는 생략하고, 제목을 넣을 공간을 확보한다.
- 표지는 글 전체의 질문을, 본문 이미지는 해당 절의 설명을 맡는다.
- 생성 이미지가 논지의 반대를 암시하지 않는지 본다. 예를 들어 ‘관계 회수’를 그리며 사람들을 기업 소유물이나 수집 대상으로 표현하면 04번 글의 취지와 어긋난다.

프롬프트 구성 예시:

> 용도·비율: [아티클 표지 또는 본문, 사용할 비율]. 핵심 의미: [본문이 실제로 주장하는 한 문장]. 장면: [주체·행동·공간과 시각적 비유]. 구도: [시선 흐름·중심 요소·제목 여백]. 스타일: [프로젝트에서 확인한 색감·질감]. 문자: [없음 또는 정확한 문구]. 보존: [중요한 조건]. 피할 오해: [본문과 반대되는 인과나 의미].
