# Ask Lazynote

여섯 개 스킬 중 뭘 써야 할지 모르겠으면 여기서 고른다. 자동으로 트리거되지 않으니 `/lazynote:ask-lazynote`로 직접 부른다.

## 라우팅

| 지금 상태 | 알아보는 법 | 가는 곳 | 하지 않는 것 |
| --- | --- | --- | --- |
| 이미 쓴 글의 교정·윤문만 필요 | "맞춤법만", "자연스럽게 다듬어줘" | `lazynote-korean-editing` | 시리즈 기획 인터뷰로 확대하지 않는다 |
| 이미 있는 원고에 이미지 필요 | "이미지 만들어줘", "이 도표 맞춰줘" | `lazynote-article-images` | 기획 인터뷰 없이 바로 시작한다 |
| 목차·개요가 이미 있다 | 쓸 내용의 뼈대가 이미 잡혀 있다 | 장르에 맞는 스킬(`lazynote-case-writing`/`lazynote-author-writing`/`lazynote-persona-writing`). 목차 자체를 다시 점검하고 싶으면 `lazynote-title-outline` | 있는 목차·개요를 새로 만들지 않는다 |
| 주제는 설명할 수 있는데 구조가 없다 | 뭘 쓰고 싶은지는 말할 수 있다 | 쓰려는 장르 스킬을 그대로 부른다 — 목적·독자·전체 목차가 비어 있으면 스킬이 알아서 `shared/intake.md` 기획 인터뷰로 넘어간다 | 인터뷰 질문에 처음부터 완성된 답을 만들 필요 없다 — 질문마다 추천 답이 붙어서 승인·수정만 하면 된다 |
| 아직 뭘 쓰고 싶은지도 불명확하다 | 소재 자체가 안 잡혀 있다 | 쓰고 싶은 장르 스킬을 그대로 부른다. **한 편만 먼저 써 본다** | 시리즈 전체를 기획하려 들지 않는다 — 인터뷰가 뜨더라도 완료 조건은 목적·독자, 이번 편이 답할 질문 정도면 된다(핵심 개념 0개도 가능). 나머지는 미정으로 두고 일단 쓴다. 전체 목차는 두세 편 쌓인 뒤 다시 잡는다 |

## 스킬 요약

| 스킬 | 쓰는 때 |
| --- | --- |
| `lazynote-case-writing` | 1차 출처로 검증한 기업 사례 분석 아티클 |
| `lazynote-author-writing` | 기본 저자 본인의 경험을 담은 개인 에세이 |
| `lazynote-persona-writing` | 다른 사람의 목소리로 쓰는 글 |
| `lazynote-title-outline` | **이미 있는** 원고·아이디어의 제목·목차를 설계하거나 점검. 재료 자체가 없으면 위 세 스킬 중 하나로 먼저 간다 |
| `lazynote-korean-editing` | 이미 쓴 아티클·에세이·보고서·이메일·안내문의 맞춤법·교정·윤문 |
| `lazynote-article-images` | 이미 있는 원고에 맞는 도표·차트·표지·썸네일 이미지 |
