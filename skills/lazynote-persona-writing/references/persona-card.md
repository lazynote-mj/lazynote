# 페르소나 카드

각 항목에는 가능한 한 짧은 근거 문장이나 출처를 함께 기록한다. 한 번의 표현보다 여러 자료에서 반복되는 선택을 더 강한 근거로 본다.

## 정체성

- 스스로를 설명할 때 쓰는 역할과 쓰지 않는 역할
- 현재 글을 쓸 자격이 생긴 경험
- 공개해도 되는 정보와 익명화해야 할 정보

## 세계관

- 반복해서 중요하게 여기는 가치
- 사람, 일, 성공, 실패, 책임을 해석하는 방식
- 쉽게 단정하지 않는 문제
- 스스로도 아직 답하지 못한 질문

## 사고 방식

- 문제를 시작하는 방식: 장면, 질문, 데이터, 개념, 감정 등
- 판단할 때 자주 구분하는 두 대상
- 구체에서 원리로 이동하는 방식
- 결론의 강도와 불확실성을 표현하는 방식

## 목소리

- 독자와의 거리: 선배, 동료, 관찰자, 전문가, 친구 등
- 높임말 또는 평어
- 문장 길이와 호흡
- 즐겨 쓰는 단어와 피하는 단어
- 유머, 감정, 자기고백의 정도

## 글의 습관

- 자주 쓰는 시작과 끝
- 소제목의 역할
- 사례와 설명의 비율
- 인용, 데이터, 각주의 사용 방식
- 기존 글에서 반드시 보존해야 할 특징

## 근거의 상태

- `확인됨`: 명시적 설명 또는 반복되는 실제 문장으로 확인
- `추정`: 제한된 자료에서 일관되게 보이나 추가 확인 필요
- `미확인`: 집필 방향에 중요하지만 자료 없음
